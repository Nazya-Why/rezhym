# Режим — жорсткий трекер дисципліни

Веб-застосунок у стилі iOS (Liquid Glass), що встановлюється на iPhone як звичайний застосунок.
Працює без сервера, а з Supabase синхронізує дані між усіма пристроями.

## Як це працює

- **Звички** повторюються за розкладом (дні тижня, час, ціль на день: «8 склянок»).
- **Задачі на день** — одноразові цілі на конкретну дату.
- **Обовʼязкові** справи вирішують, чи зараховано день. Пропустив хоч одну, і день провалено, серія обнуляється.
- **Час**: якщо справа має час, після нього (плюс допуск, за замовчуванням 15 хв) вона стає червоною «Прострочено».
  Виконане пізніше позначається як «Із запізненням». У налаштуваннях можна ввімкнути «Запізнення = провал».
- **Минулі дні заблоковані**: заднім числом нічого не відмітиш.
- **Фокус** — таймер Pomodoro. Сесії зберігаються й рахуються в статистиці.
- **Прогрес** — серія, рекорд, % зарахованих днів, карта дисципліни, статистика кожної звички.

## 1. Підключити базу даних (Supabase, безкоштовно)

1. Зареєструйся на supabase.com → **New project** (регіон: Frankfurt або найближчий).
2. **SQL Editor → New query**, встав вміст файлу `supabase.sql` і натисни **Run**.
3. **Authentication → Sign In / Providers → Email**: для простоти можна вимкнути **Confirm email**,
   тоді акаунт працюватиме одразу, без листа.
4. **Project Settings → API**: скопіюй **Project URL** і **anon public** ключ у `js/config.js`:

   ```js
   export const SUPABASE_URL = 'https://xxxx.supabase.co';
   export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
   ```

   anon-ключ публічний, його можна комітити. Дані захищені правилами в `supabase.sql`:
   кожен бачить тільки свій рядок.

## 2. Викласти на GitHub Pages

1. Створи репозиторій на GitHub (наприклад `rezhym`) і завантаж туди всі файли цієї папки.
2. **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. Через хвилину сайт буде доступний за адресою `https://<твій-нік>.github.io/rezhym/`.
4. У Supabase: **Authentication → URL Configuration → Site URL**: встав цю адресу.

## 3. Поставити на iPhone

Відкрий сайт у **Safari → Поділитися → «На початковий екран»**.
Застосунок відкриватиметься на весь екран зі своєю іконкою. Усередині увійди в акаунт
(іконка людини вгорі → email і пароль), один раз на кожному пристрої.

## Оновлення

Після змін у коді збільш версію в `sw.js` (`rezhym-v1` → `rezhym-v2`),
щоб встановлені на телефоні копії підхопили нову версію.

## Структура

| Файл | Що всередині |
|---|---|
| `index.html` | каркас сторінки, таббар |
| `css/style.css` | дизайн: скло, кольори iOS, світла й темна теми |
| `js/app.js` | екрани, шторки, таймер, дії |
| `js/store.js` | дані й правила: статуси, зарахування дня, серії |
| `js/sync.js` | вхід і синхронізація із Supabase |
| `js/config.js` | ключі Supabase |
| `sw.js`, `manifest.webmanifest` | офлайн-режим і встановлення як застосунок |
| `supabase.sql` | таблиця і правила доступу |
